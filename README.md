# Educated & Proud

A web application built for first-generation college students in California
navigating community college, transfer planning, financial aid, and everything
in between. Built by a first-gen student, for first-gen students.

## Why This Exists

Too many students show up to community college without a roadmap. This app is
the resource I wished I had at 18 — honest, clear, and built for people
navigating a system that was not designed with them in mind.

## Getting Started

### Backend
1. Navigate to `educated-and-proud-api`
2. Copy `application.properties.example` to `application.properties`
3. Fill in your local PostgreSQL credentials
4. Run `./mvnw spring-boot:run`

### Frontend
1. Navigate to `educated-and-proud-ui`
2. Run `npm install`
3. Run `npm run dev`
4. Open `localhost:5173`

## Tech Stack
- Frontend: React + Vite
- Backend: Java 17 + Spring Boot
- Database: PostgreSQL
- Deployment: Vercel (frontend) + Render (backend)
